# Veri seti

Bu klasörde kullanılan veri seti `Telco-Customer-Churn.csv` dosyasıdır.

Dosya, IBM'in açık kaynak GitHub deposundaki Telco Customer Churn veri
setinden alınır:

https://github.com/IBM/telco-customer-churn-on-icp4d

`telco_churn_analysis.py` ilk çalıştırıldığında dosya bu kaynaktan otomatik
olarak indirir ve aynı klasöre kaydeder. İstenirse indirilen CSV dosyası da
repository'ye eklenebilir.
